# public/models/

ここに `avatar.vrm` を置くと、プロフィール(`/profile`)のヒーローセクションに
VRMモデルが表示されます。

- ファイル名は必ず `avatar.vrm` にしてください(`src/components/vrm/VrmCanvas.tsx` が
  `/models/avatar.vrm` を固定パスで読み込みます)。
- ファイルがまだ無い場合や読み込みに失敗した場合は、ミクティールのグラデーション球
  (プレースホルダ)が代わりに表示されます。エラーにはならないので、まずはこの
  READMEの状態のままデプロイしても問題ありません。
- 再配布ライセンスの都合上、サンプル・仮モデルはこのリポジトリに同梱していません。
  各自が利用許諾を確認したVRMモデルを配置してください。

## happy-sway.vrma

ヒーローでループ再生される待機アニメーション(ニコニコ笑顔で左右に揺れる、3.2秒/シームレスループ)。
vrma-create スキルで生成したVRMA 1.0ファイルです。

- 読み込みパスは `/models/happy-sway.vrma` 固定(`VrmCanvas.tsx`)。
- このファイルが無い/読めない場合は、コード内蔵のプロシージャル待機モーション
  (呼吸・微揺れ・まばたき)に自動フォールバックします。
- 差し替えたい場合は同名で上書きするだけでOK(体の回転トラック+expressions対応)。
