# はじめに
7/28～8/31の4日間，
伊豆大島に行ってきた．
大学のサイクリング部で毎年やっている恒例行事で，東京の竹芝から伊豆大島に向けて出ているフェリーに自転車とキャンプ用具をを積んで，伊豆大島に行く．
今年は大学4年ということもあり，参加できる最後の伊豆大島合宿だった．

このブログでは，どんな感じの行程だったのかというのを日記程度に書き残しつつ，来年伊豆大島合宿への参加を迷っている後輩と，自転車で大島に行くという人がいれば旅の計画の参考になればと思ってこの記録を書いている．

## 装備に関して
昨年は，3泊4日のキャンプ(うち1泊は行きのフェリー内)の装備ということで，テントに加え，島での生活に必要な消耗品から遊泳道具まで，物品を揃えて全て自転車に積載するバイクパッキング方式で臨んだが，今年の伊豆大島では，昨年バイクパッキングによって輪行が面倒くさくなったり，港からキャンプ場までの長い登りで重心が高くなってしまって走りにくいという反省から思い切った装備の変更を行った．
先代の先輩が行っていたというUber Eatsのバッグの中にテントや寝袋から着替えまで，すべてひとつのバッグで背をってしまい，自転車への積載は一切しないという方法．
半信半疑で同じ方法で今回の合宿に臨んだが，これが意外なことに，肩への負担はあるものの，自転車本体の重心バランスが変わらないため，道中の上りが断然楽だった．加えて，初日の隣町への夕食の開始においても，Uberバッグの保冷により，冷蔵庫のない島での生活においては大変重宝した．
またキャンプを伴う自転車旅では同じ装備で臨むかもしれない．

# 旅路
## 1日目. 竹芝 → 伊豆大島
伊豆大島への移動手段には，東京〜伊豆大島〜利島〜新島〜式根島〜神津島航路に就航する東海汽船「さるびあ丸」を利用した．竹芝出航が23時で，翌日6時に伊豆大島に到着する．初日は夕方から竹芝フェリーターミナルに集合し，夕食や，翌朝の食料の調達など，各自出港に備えた．昨年は何事もなく出港までのんびりと過ごすことができたが，今年はまさかの部で持ち込むガスコンロに不備があり，竹芝から部室に荷物を取りに出戻りが発生．なんだかんだで全員の準備が整ったのは乗船可能になる1時間前とかだった気がする．とはいえ全員無事に乗船することができたので初日はひと安心．無事大島に向けて出港

我々が利用する和室二等船室は，学生料金の場合一人あたり15000円で竹芝と大島の往復ができる．船上ビアガーデンがあり，行きの夜便では東京の夜景を展望できるほか，帰りの船では太平洋上で船尾のデッキから海を眺めながらのんびり過ごせるため，移動のための費費用にしてはとても破格だと思う．(二等和室での雑魚寝も床が硬くて寝苦しいが一日くらいは我慢)

![行きの船上から見た東京レインボーブリッジ](/images/blog/20260728/rainbow.jpg)
## 2日目．伊豆大島初日！
初日は港からキャンプ場に移動し，キャンプ地を設営します．
伊豆大島の港は「岡田港」と「元町港」の2つがあり，発着場所に関してはその日の海運状況に応じて毎回異なります
(帰りの便がどこの港からになるのかで最終日の移動行程が大きく変わるので近い港になることを毎年祈ってます笑)．

:::note info
実は東京発の夜行便はよほどのことがない限り[岡田港になっている](https://odschool.jp/tokyo/column-tokyo/%Es3%80%90%E6%9D%B1%E6%B5%B7%E6%B1%BD%E8%88%B9%E3%80%91%E5%A4%A7%E5%9E%8B%E8%88%B9%E3%81%A7%E6%97%A9%E6%9C%9D%E3%81%AB%E5%A4%A7%E5%B3%B6%E5%88%B0%E7%9D%80%EF%BC%81%E3%81%8A%E5%BA%97%E3%81%8C%E9%96%8B/) らしいです．
:::

私たちが利用する「トウシキキャンプ場」は，無料で伊豆大島の南西に部分に位置しています．
そう．島の北東部に位置する岡田港からキャンプ場までは20kgを超えるキャンプ道具を車載/担いだ状態で20kmのアップダウンを伴う道中が存在します．
![行きのストラバログ](/images/blog/20260728/start.png)

冒頭に述べた通り，今年は車載をやめUberのバッグで全て背負うスタイルだったのでどうなるかと思いましたが，肩の疲労は重いのほか少なく，自転車が安定している分，昨年よりも楽にキャンプ場に着くことができた気がしています．

キャンプ場の場所取りのため，4回生2人が先に先発隊として出発し，その後私含む残りの4回生と上回生で，1，2回生を連れて二班に分かれてキャンプ場を目指しました．
毎年慣れない装備の量を背負って登坂を行うことから，苦労する一年生が多い中，今年は皆自力で山を乗り越えており，順調だったと来ています．

> 初のパニアバッグで臨んだ4回生が機材トラブルでひどい目にあったのはここだけの話...


![伊豆大島に配達](/images/blog/20260728/haitatsu.jpg)

### キャンプ地 - お昼
全員がキャンプ場に到着したとは各自テントを設営します．その後，スーパーのある元町港を目指し，昼ご飯を食べ，夕飯の買い出しを行います．

快晴の空の下．自然の中での生活は普段の情報に追われる生活とは違って心も休まる良い場所です
![テントの設営](/images/blog/20260728/camp.jpg)
また，昨年は老朽化に伴い利用できなかった屋根のあるベンチがあったのですが，1年ぶりに訪れてみると，とても立派な屋根のベンチにリニューアルされていました．
後述する大島一周TTの後や，水浴び後の休憩など，みんなで日光をさけて休憩する際にはとても快適な設備が出来上がっていました．

トウシキキャンプ場から元町までは約15キロ．行きの港からの移動では大荷物によって苦しい思いをしたアップダウンも，荷がおりてしまえばとても気持ちがいい道．進行方向の左手には常にきれいな海が見える状態で，元町港まで向かいます．

![お昼ごはん](/images/blog/20260728/hiru1.jpg)

> 「丸久食堂」の他人丼．いつもは初日に「寿し光」というお店で[べっこう丼](https://oshima-navi.com/gourmet/bekko01.html)を食べるのですが，まさかの水曜定休日でお休み．丸久食堂さんは初めて行くお店でしたが，ボリュームも味も絶品．またおすすめの大島飯が増えました．


https://tabelog.com/tokyo/A1331/A133101/13236745/

昼ごはんを済ませた後は，すぐ近くある島で一番大きなスーパー「[ベニヤ](https://share.google/l06um4PGvgjevTZCQ)」で夕食の買い物を済ませます．

:::note warn
この時点で時刻は14:00.1日の中でも最高気温に．熱中症に注意してキャンプ場に戻ります．
:::

### 買い出し後 - 夕食
夕食の時間までは自由時間です！各々キャンプ場周辺で自由に過ごします．
昼寝をしてもよし，散歩をしても，自転車に乗っても，
私たち4回生は海に入った．
今回キャンプ地としているキャンプ場のすぐ下には，遊泳場があり，海水浴ができます．
普段見ている千葉海のは大違い，透き通った海で魚も普通に見えます．(監視員さん曰くクラゲもいるらしいので刺されないように注意)

:::note
遊泳期間：例年7月中旬から8月中旬まで。期間中は監視員が常駐し、安全に配慮されています。
営業時間：9:00〜16:00（監視・救護所の対応時間）
岩場が多いため、マリンシューズの着用をおすすめします，
:::

↓ 毎年恒例，岐阜の[ポーズ](https://dic.pixiv.net/a/%E5%B2%90%E9%98%9C%E3%81%AE%E3%83%9D%E3%83%BC%E3%82%BA)で海にダイブ
![遊泳場での様子](/images/blog/20260728/umi.jpg)


海で思う存分遊んだ後は，キャンプ場に設置されたシャワーで体を流し，夕食までのんびりします．
(夕日が沈み始める頃にテントの中でデジタルデトックス)

初日の夕ご飯は1，2年生たちが担当．炊飯器を使わない鍋での炊飯に苦戦しつつも，おいしいカレーができました．
![夕飯のカレー](/images/blog/20260728/yoru1.jpg)


## 3日目．大島一周TT
伊豆大島2日目のメインイベントは伊豆大島一周TT(タイムトライアル)です！
約91.06平方キロメートル（山手線の内側とほぼ同じ広さ）ある大島のうち，トウシキキャンプ場を起点として全長約46.6kmある大島一周道路を一人ずつ走っていきます．

結果は1時間54分．昨年は2時間を超えていた気がしたので自己ベスト更新できて良かったです...
![大島一周TTの結果](/images/blog/20260728/tt.png)

:::note
今年の走った人の中での最速記録は1時間34分．
過去の先輩の中には1時間20分台で走る人も．
来年以降に参加する後輩のみんな頑張って！
:::

トウシキキャンプ場から1km程度のところにある「あさみ」さんでうどんを食べました．
1日の中で最も暑い時時間と，TTで疲れた体も相まって，冷たいうどんが体に沁みます．

昨年は伊豆大島の中心部にある三原山頂に広がる裏砂漠に行ったのですが，今年は疲労もあり同期と近場を散策することに．

### 波浮港
これまで行ったことのなかった波浮港の下におりてみることにしました．

波浮港は1801年に開港した港で，木造の古民家や，裏路地，斜面に露出した地層などから，昔ながらの港街といった街並みを感じれます．

![波浮港上からの様子](/images/blog/20260728/habu1.jpg)

https://ja.wikipedia.org/wiki/%E6%B3%A2%E6%B5%AE%E6%B8%AF

今でも漁船や貨物船も立ち寄る港なので港のそばで座ってゆっくり船を眺めてみたり，自転車をおりて当時の街並みを想像しながら散策しているだけでも楽しい体験でした．
![波浮港に停泊した船舶](/images/blog/20260728/habu2.jpg)

また，ちょうど合宿を行ったには，同時に2026年夏アニメとして放送されていた『これ描いて死ね』の放送開始時期とも被っていたこともあり，島全体で聖地巡礼スタンプラリーを開催していたり，所々にフライヤーが掲載されておりより一層活気づいていました．中でもここ波浮港は，作品の中で登場するキャラクターたちの生活圏としてより忠実に描かれており，作中のキャラクター「藤森心」の実家のモデルと思われる，「踊子の里資料館（旧港屋旅館）」には等身大パネルや，原作者さんのイラストともに書き置きも残されていました．

:::note info
『これ描いて死ね』は，「伊豆王島」（伊豆大島がモデル）を舞台に、憧れの漫画家との出会いをきっかけに漫画研究会を設立した女子高校生・安海相と仲間たちが、漫画制作に挑む青春劇。2023年「マンガ大賞2023」大賞、2025年第70回小学館漫画賞を受賞。
TVアニメは2026年7月3日より日本テレビ系『FRIDAY ANIME NIGHT』枠にて放送開始（監督：赤城博昭、アニメーション制作：シンエイ動画）。制作にあたり美術・作画スタッフが伊豆大島で実地取材を行い、島の景観を丁寧に描写している。
:::

合宿を機に実際にこの作品を毎週視聴中ですが，実査に行ったことのある伊豆大島の町並みが忠実に再現されていて，島の中の見知った素敵な景色や，コミティアといった，実在する漫画に関わりのあるイベントの話もあり，ワクワクする作品だと思います．

## 4日目 最終日
名残惜しいですが，今日が伊豆大島最終日です．東京本土への帰宅に備え，撤収準備を進めます．
お借りしたキャンプ場を管理されている方々に挨拶を済ませ，身の回りの片付けを済ませた後，元町を目指して4日間の疲れを癒すべく温泉に入って，各自お土産を買います！

https://share.google/ZP8Zj6pXGIqtPyTlS

![撤収完了](/images/blog/20260728/uber.jpg)

そして，前述の通り，最終日には主発港ガチャが待っています．初日の到着港である岡田港か，重い荷物を再度背をった状態で，お風呂上がりに5kmの山道の有無が変わります．


ネットにて確認できる当日の出発港は...




**元町港です！！！**

勝ちました．入浴後に，のんびりした後も，船の出発までかなり時間があったので，伊豆大島1日目に逃してしまったべっ甲丼にリベンジします．
![伊豆大島のべっ甲丼](/images/blog/20260728/hiru4.jpg)
やはりこれを食べると伊豆大島に来たなという感じがします．来年もこのためだけにも伊豆大島に訪れたいくらいに好物です．


ご飯を済ませた後は，名残で惜しいですが，伊豆大島ともお別れです．合宿前日の東京の天気はあいにくの雷雨に見舞われましたが，伊豆大島に滞在した4日間は見事に晴れてくれました．
ありがとう伊豆大島！
![帰りの船から見た伊豆大島](/images/blog/20260728/end.jpg)


夜行便とは違い，船上のデッキも開放されているため，4時間半の航路も仲間たちとのんびり海風をびながら談笑することができます．今回搭乗しているさるびあ丸は，竹芝にて船上ビアガーデンさるびあとしても運用されていることもあり，後方デッキはビアガーデンになっています．見渡す限りが青い海の中，のんびりお酒が飲めるのも合宿の最後の醍醐味です．

![海の上の氷結](/images/blog/20260728/beer.JPG)
:::note alert
この日の乗船数時間前に船長がサルBeerしてしまって業務停止命令が報道されたのはここだけの話🤫

# 最後に
学生最後の伊豆大島合宿，本当に楽しかったです．
キレイな景色に優しい島の人たち，重い荷物を皆で分担して乗り越えたキツい坂，伊豆大島で感じる全ての体験が，とても大切な思い出として残っています．

そして何より，非日常を共にした同期をはじめとした，サイクリング部のメンバーとの島での共同生活が今でもかけがえのない思い出です．！
私は今年で大学を卒業してしまいますが，またいつか，社会人になってもこのメンバーで一緒に自転車で旅ができることを願っています．
本当にありがとうございました...!
